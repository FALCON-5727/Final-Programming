This project is a turn-based RPG combat system inspired by the TTRPG Ordem Paranormal, developed in C++ using Visual Studio.

The project includes:
- Character and enemy systems
- Dice rolling mechanics
- Skill checks
- Turn-based combat
- Rituals
- Inventory and healing items
- Combat distance system
- Dodge and block reactions
- Multiple enemy encounters

The player fights enemies in sequence using different combat mechanics and character abilities.

## How to Run
Open the project in Visual Studio and run the program.
